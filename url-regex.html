Regex for HTTP and HTTPS URLs

Use a URL regex when you need to find web links inside text or validate a constrained URL format. Real-world URLs can be complex, so test the pattern against the cases your application actually expects.

https?:\/\/(www\.)?[-a-zA-Z0-9@:%._+~#=]{1,256}\.[a-zA-Z0-9()]{1,6}\b([-a-zA-Z0-9()@:%_+.~#?&\/=]*)

Open playground and test examples →

What the main pieces do

  • https? accepts either http or https.
  • The escaped slashes match the :// separator.
  • The optional www group handles URLs with or without that prefix.
  • The remaining sections match a practical domain and path/query shape.

Test before relying on it

URL syntax contains many valid edge cases. Use the live regex tester with examples from your own data and tighten or relax the expression based on your actual requirements.
