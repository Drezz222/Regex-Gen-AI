Regular-expression syntax reference

Regex cheat sheet

A quick reference for the JavaScript-style regex syntax you will use most often. Open the full re/gen tool for the interactive cheat sheet, pattern library and live testing.

Character classes

.Any character except line terminators by default
\dDigit
\wWord character
\sWhitespace
[abc]One listed character
[^abc]One character not listed

Quantifiers

*Zero or more
+One or more
?Zero or one
{3}Exactly three
{2,5}Between two and five

Anchors & boundaries

^Start of input or line in multiline mode
$End of input or line in multiline mode
\bWord boundary
\BNot a word boundary

Groups & alternatives

(abc)Capturing group
(?:abc)Non-capturing group
a|bMatch a or b
(?=abc)Positive lookahead
(?!abc)Negative lookahead

Common flags

gFind all matches instead of stopping after the first
iCase-insensitive matching
mMultiline behavior for ^ and $
sDot also matches newline characters
uUnicode-aware matching
