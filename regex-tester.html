How to test a regex

  1. Open the playground and type your regular expression.
  2. Choose flags such as g, i or m.
  3. Paste a test string and review highlighted matches.
  4. Use the Groups or Replace tabs to inspect behavior beyond a simple match count.

What the tester shows

The playground includes live highlighting, capture-group extraction, replacement preview, token breakdown and copyable code snippets. It uses the JavaScript regular-expression engine in your browser.
