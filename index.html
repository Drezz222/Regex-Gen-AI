FAQ

Regex questions.

Which regex flavor does re/gen test?

The live playground uses the JavaScript regular-expression engine in your browser. Most everyday regex syntax transfers well, but advanced features can differ between JavaScript, PCRE, Python, .NET and other engines.

Can I build regex without memorizing syntax?

Yes. The visual builder assembles common pattern parts and shows the generated expression, which you can then test in the playground.

Does re/gen include common regex patterns?

Yes. The library contains patterns for common validation and extraction tasks such as email, URL, IPv4, UUID, phone numbers, semantic versions and more.
